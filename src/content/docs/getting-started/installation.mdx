## Requirements

| | |
| --- | --- |
| Node.js | `>= 20` |
| TypeScript | `>= 5.0` |
| Package manager | pnpm (recommended), npm or Yarn |

Gland relies on `reflect-metadata` for decorator metadata, and on `experimentalDecorators`
plus `emitDecoratorMetadata` from TypeScript. Both are set up for you below.

## Create a project

<Steps>

1. **Scaffold a TypeScript project.**

   ```bash
   mkdir my-app && cd my-app
   pnpm init
   ```

2. **Install the runtime packages.**

   For an HTTP application. Swap `@glandjs/express` for whichever transport you want —
   `@glandjs/fastify`, `@glandjs/koa`, `@glandjs/hono` or `@glandjs/node`. Only one of
   them is ever needed:

   <Tabs syncKey="pkg">
     <TabItem label="pnpm">
       ```bash
       pnpm add @glandjs/core @glandjs/common @glandjs/events @glandjs/http @glandjs/node reflect-metadata
       ```
     </TabItem>
     <TabItem label="npm">
       ```bash
       npm install @glandjs/core @glandjs/common @glandjs/events @glandjs/http @glandjs/node reflect-metadata
       ```
     </TabItem>
     <TabItem label="yarn">
       ```bash
       yarn add @glandjs/core @glandjs/common @glandjs/events @glandjs/http @glandjs/node reflect-metadata
       ```
     </TabItem>
   </Tabs>

   <Aside type="tip" title="Only install what you use">
     `@glandjs/core`, `@glandjs/common` and `@glandjs/events` are the framework.
     `@glandjs/http` and one adapter are only needed if you serve HTTP. Drop them and you
     have a transport-agnostic event application. `@glandjs/node` is the cheapest way in:
     it pulls in no HTTP server at all, because `node:http` is already in the runtime.
   </Aside>

3. **Install the toolchain and `reflect-metadata`.**

   `reflect-metadata` is a peer dependency of `@glandjs/core` and `@glandjs/common`:

   <Tabs syncKey="pkg">
     <TabItem label="pnpm">
       ```bash
       pnpm add -D typescript @types/node
       pnpm add reflect-metadata
       ```
     </TabItem>
     <TabItem label="npm">
       ```bash
       npm install -D typescript @types/node
       npm install reflect-metadata
       ```
     </TabItem>
     <TabItem label="yarn">
       ```bash
       yarn add -D typescript @types/node
       yarn add reflect-metadata
       ```
     </TabItem>
   </Tabs>

4. **Configure `tsconfig.json`.**

   The three options below are required. `useDefineForClassFields` must be `false`, or
   decorator metadata is lost.

   ```json title="tsconfig.json"
   {
     "compilerOptions": {
       "target": "ES2022",
       "module": "NodeNext",
       "moduleResolution": "NodeNext",
       "strict": true,
       "experimentalDecorators": true,
       "emitDecoratorMetadata": true,
       "useDefineForClassFields": false,
       "skipLibCheck": true,
       "outDir": "dist"
     },
     "include": ["src"]
   }
   ```

5. **Verify the installation.**

   ```ts title="src/main.ts"
   import 'reflect-metadata'
   import { EventBroker } from '@glandjs/events'

   const broker = new EventBroker({ name: 'smoke-test' })
   broker.on('ping', (payload) => console.log(payload))
   broker.emit('ping', { ok: true })
   ```

   ```bash
   npx tsc && node dist/main.js
   # { ok: true }
   ```

</Steps>

## Package reference

| Package | What it gives you | Install it if |
| --- | --- | --- |
| [`@glandjs/core`](/packages/core) | DI container, module bootstrap, lifecycle hooks, `Context` | always |
| [`@glandjs/common`](/packages/common) | `@Module`, `@Controller`, `@Channel`, `@On`, `@Inject` | always |
| [`@glandjs/events`](/packages/events) | `EventBroker`, channels, mesh networking, `IOEvent` | always |
| [`@glandjs/emitter`](/packages/emitter) | Standalone zero-dependency event emitter | you want a pub/sub primitive without the framework |
| [`@glandjs/http`](/packages/http) | Route decorators, `HttpContext`, the middleware onion, `HttpCore`, `HttpBroker` | you serve HTTP |
| [`@glandjs/express`](/packages/express) | The Express 5 adapter | you use Express |
| [`@glandjs/fastify`](/packages/fastify) | The Fastify 5 adapter | you use Fastify |
| [`@glandjs/koa`](/packages/koa) | The Koa 3 adapter | you use Koa |
| [`@glandjs/hono`](/packages/hono) | The Hono 4 adapter, on Node and the edge | you want Fetch or an edge runtime |
| [`@glandjs/node`](/packages/node) | The `node:http` adapter, zero dependencies | you want no framework at all |

Pick **one** adapter. They are interchangeable: the same controller runs unchanged on
any of them, and only the `connectTo()` line differs. The
[adapter matrix](/reference/http/adapter-matrix) is the honest comparison.

<Aside type="tip" title="Reflect metadata is not optional">
  `reflect-metadata` is a **required** peer dependency of `@glandjs/http` and every
  adapter, and `experimentalDecorators` / `emitDecoratorMetadata` must be on in
  `tsconfig.json`. The decorators are the only way the framework discovers your
  application — there is no naming convention and no config file.
</Aside>

## Optional extras

`@glandjs/http` has no runtime dependencies beyond the toolkit. A few adapter features
are peer dependencies marked optional, and each one throws a message naming the package
rather than failing with `undefined is not a function`.

| Adapter | Install for | Package |
| --- | --- | --- |
| `@glandjs/express` | multipart | `multer` |
| `@glandjs/fastify` | cookies, forms, static, multipart | `@fastify/cookie`, `@fastify/formbody`, `@fastify/static`, `@fastify/multipart` |
| `@glandjs/koa` | body parsing, static, multipart | `koa-bodyparser`, `koa-static`, `@koa/multer` |
| `@glandjs/hono` | listening on Node | `@hono/node-server` |
| `@glandjs/node` | nothing | — |

CORS, cookies, problem details and SSE are implemented **inside** `@glandjs/http` and
need nothing installed.
